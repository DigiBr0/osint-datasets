# OSINT Datasets

A curated library of publicly available datasets, investigative resources, and research tools for Open Source Intelligence (OSINT).

---

## About

OSINT Datasets is an open-source project dedicated to collecting, organizing, and documenting publicly available datasets used in Open Source Intelligence (OSINT), cybersecurity, digital investigations, journalism, geospatial intelligence (GEOINT), and data analysis.

This repository aims to provide a centralized resource where students, researchers, analysts, and investigators can quickly discover trustworthy public data sources and understand how they can be applied in real-world investigations.

---

## Mission

Our mission is to make public datasets easier to discover, understand, and use responsibly while promoting ethical and legal OSINT practices.

---

## What You'll Find

- Government datasets
- Cybersecurity resources
- Geospatial (GIS) data
- Weather and climate datasets
- Transportation data
- Financial datasets
- Demographic information
- Crime and justice data
- Health datasets
- Infrastructure resources
- Investigation templates
- OSINT reference materials

---

## Project Goals

- Build a high-quality collection of public datasets
- Document trusted data sources
- Explain investigative use cases
- Create a valuable learning resource for OSINT practitioners
- Continuously expand and improve the collection
